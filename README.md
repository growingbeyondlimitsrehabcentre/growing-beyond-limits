# Growing Beyond Limits Rehab Center — Website

A free, responsive, cinematic occupational therapy website.

## Files
- `index.html` — complete website
- `assets/logo.png` — your supplied logo

## Quickest free launch
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload `index.html` and the `assets` folder.
4. In GitHub: Settings → Pages → Deploy from branch → main → /(root).
5. GitHub will give you a free `github.io` website address.

## Before publishing
Replace the “Your Therapist” placeholder with your name, qualifications and photo.
Add your WhatsApp number, clinic address, email and hours in the contact section.
Review service wording so it precisely reflects the services you provide.
